How this works
  1. Pick or create a post. Starting from a template saves time.
  2. Write on the left, the page on the right updates as you type. Use the toolbar or Discord style formatting.
  3. Review and publish. A checklist tells you what to fix, then the site updates in about a minute.
Press ? anywhere for shortcuts. The Help button brings this back.

Every post is a JSON file in its folder. Deleting a post deletes its file.

    Formatting guide

    Works in Text, Lists, Q&A answers, Quotes, Callouts and Table cells. Shortcuts: Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+K link, Ctrl+E code, Ctrl+Shift+X strike, Ctrl+Shift+P spoiler.

    **bold**Bold
    *italic* or _italic_Italic
    __underline__Underline
    ~~strike~~Strikethrough
    ***bold italic***Combine styles, nest freely: __**both**__
    ||spoiler||Hidden until the reader clicks
    `inline code`Inline code
    ``` code block ```Code block (nothing inside is formatted)
    # Big ## Medium ### SmallHeadings, at the start of a line
